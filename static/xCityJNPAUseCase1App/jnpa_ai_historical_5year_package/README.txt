JNPA AI Historical 5-Year Package

What this package contains
- five years of synthetic historical data aligned to the currently deployed CSV schemas
- separate yearly folders for:
  - berth_crane_operations.csv
  - container_master.csv
  - customs_events.csv
  - digital_twin_events.csv
- one ML-ready training dataset for XGBoost:
  - jnpa_ai_training_dataset_2022_2026.csv
- one XGBoost training pipeline:
  - train_xgboost_insights.py
- yearly KPI summary CSV

Important note
- this is synthetic historical data created to continue the already deployed data structure
- it is suitable for UI integration, feature engineering, model prototyping, and insight-layer testing
- it is not real historical operational data

Target years included
- 2022
- 2023
- 2024
- 2025
- 2026
